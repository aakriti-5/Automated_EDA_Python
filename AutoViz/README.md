# AutoViz

## Overview
AutoViz is an automated Exploratory Data Analysis (EDA) library that generates visualizations with minimal code.

## What I Learned
- Installing and configuring AutoViz
- Generating automated visualizations
- Understanding feature relationships
- Identifying patterns in datasets quickly

## Advantages
- Fast visualization generation
- Easy to use
- Supports both small and large datasets

## Note
AutoViz helps speed up EDA but does not replace manual data analysis.
