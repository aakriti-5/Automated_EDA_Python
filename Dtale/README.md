# D-Tale

## Overview
D-Tale is an interactive EDA tool that allows dataset exploration through a web-based interface.

## What I Learned
- Launching D-Tale from Python
- Interactive data inspection
- Filtering and sorting data
- Generating visualizations directly from the interface

## Advantages
- Spreadsheet-like experience
- Interactive exploration
- No need to write many plotting commands

## Note
D-Tale is useful when working with datasets that require frequent filtering and inspection.
