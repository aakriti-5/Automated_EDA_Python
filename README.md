# Automated EDA with Python

This repository contains my practice and learning of popular Automated Exploratory Data Analysis (EDA) libraries in Python.

## Libraries Covered

1. YData Profiling
2. AutoViz
3. Sweetviz
4. D-Tale

## Objective

The goal of this repository is to understand how automated EDA tools can help analyze datasets quickly and generate useful insights with minimal code.

## Key Learnings

- Automated data profiling
- Data visualization
- Missing value analysis
- Correlation analysis
- Dataset quality assessment
- Interactive data exploration

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn
- YData Profiling
- AutoViz
- Sweetviz
- D-Tale
